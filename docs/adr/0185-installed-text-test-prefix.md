Only image delivery/geometry knobs apply after the cut. Every reference/image,
original-ready boundary, geometry, restart, rollback, stop and UNKNOWN path stays

Cast/Art, budgets, portraits, compact packs, early references, writer death and

Reject caching authority/model objects, copying host/service/controller state,
manual reconstruction of installation, policy rebasing, broad fallback inputs,
and reuse of an image/geometry or completed material pack. The session prefix is
test-owned retained evidence, not creative/product acceptance or a runtime API.

Before converting consumers, prove two independent claims/copies through fresh
image attempts/receipts and geometry lineage, no text resend, rollback/mutation
isolation and unchanged source bytes. Refuse active owners, unresolved history,
nondefault inputs and corrupted retained package/delivery bytes using existing
owners. Run the complete three changed test files plus proportional fixture,
claim, authority, safety, seed and ownership regressions. Preserve failed guard
attempts and diagnoses. Register exact test/helper ownership.
