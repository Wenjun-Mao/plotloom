# Checkpoint 2 capability and UI gap map

> **Archive status (2026-09-18):** Historical/supporting record retained for context and evidence; it is not an active delivery plan or a completion claim. See [the roadmap entrypoint](../../README.md).


Approved step: Playable MVP milestone checkpoint 2, synopsis to proposal.

| Owner | Current authority | Checkpoint-2 use / gap closed |
| --- | --- | --- |
| Project Brief | Required synopsis and editable production defaults | Lead with synopsis, normalize only a blank optional working title at save, and hide DAG settings behind an advanced control. |
| Story Bible | Canonical characters, setting, premise and dramatic direction | Generate and review it directly; refinements remain in its existing editor and revision boundary. |
| Story Graph | Canonical choices, consequences and endings | Generate and review it directly; report derived node/choice/ending counts without inventing timing estimates. |
| Pipeline run | Existing contiguous canonical-stage execution and provider admission | Request only Story Bible through Story Graph; no new proposal run/store/orchestrator. |
| Workspace UI | Stage editors and generic trace view | Add a Brief-level review composition, scoped regenerate action, explicit stale guard, and navigation-only continuation. |

Exclusions: scene beats, storyboard, Gate/Approval, image/video work, provider
profile changes, retained-pilot mutation, and a general unsupported-synopsis
classifier. Stopping condition: a fresh synopsis can be reviewed, saved and
reopened as canonical Bible/Graph content before any downstream generation.
