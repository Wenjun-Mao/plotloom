## 人物

**陆敏，32 岁。** 便利店店员。明早要离开家乡，到外地开始一份新工作。

**小乔，25 岁。** 接陆敏班的新店员。第一次学独立结账，想把工作做好，也想按约定给母亲报平安。

**陆远，27 岁。** 陆敏的弟弟。

## 开场 · 最后一班

夜。雨不大，店门外的灯把地面照成一小片白。

小乔拿着交班单，在数字底下划了一道线。

“还是差两块。”

陆敏正在解工服外套，停下手。“先写差两块。”

“要不我补上吧？明天店长问起来——”

“明天他问，你就说差两块。写清楚，比你替它长出来好。”

小乔把笔尖放回纸上，认真写了个“少”。

陆敏的手机亮了一下。明早七点零五的车票提醒。小乔瞥见：“你真走啊？”

“房子的押金都交了，不走多亏。”

“不是说新工作下个月才转正？”

“嗯。先去干着。”

小乔没再追问。她拿起自己的手机，给母亲发语音：“我还要学一遍交班。你别来店门口等，我下班给你发。”发完又按住那条语音听了听，确认自己没有说漏什么，才把手机放进围裙口袋。

陆敏把收银抽屉推回去，拿起交班单，正要签最后一笔。

门铃响。

一个戴口罩和帽子的男人进来，停在收银台旁。他从衣服里拿出一把刀，握得很紧。刀尖低着，指向两人之间的地面。

“收银台的钱。拿出来。”

小乔靠门一侧，陆敏在柜台里面。男人站在柜台另一端，视线在她们之间来回。店门没有锁；此刻没人愿意试他会不会拦。

陆敏看见他握刀的手。右手虎口有一道旧疤，是小时候她给他开罐头时划的。他也看见她认出来了。

口罩上方，他的眼睛一下子乱了。他侧过身，挡住小乔的视线，用空着的手扯开口罩下沿，朝陆敏无声地动嘴唇。

**别叫我的名字。**

他立刻把口罩拉好。

陆敏的笔掉在交班单上。

## A · 名字

“陆远！”陆敏的声音比她自己想的还响，“把刀放下。”

男人猛地回头看小乔，抬起刀，又立刻停住。

小乔：“你认识他？”

陆敏看着她。“他是我弟弟。”

“你非要叫出来？”陆远隔着口罩急促地吸气，朝小乔走了半步，“你刚才听错了。”

小乔抓着自己的围裙口袋。“我听见了。”

“你别拿手机。”

小乔没有答应。她看向门：“我要出去。”

陆敏说：“她要走，我不会替你拦她。”

陆远看着姐姐，又看了一眼小乔。她没有往柜台走，也没有替任何人拿东西。他把脚从门边移开。

小乔自己出了门。她站到玻璃外，拿起手机，拨通求助电话：“我在便利店门外。里面有人拿刀。店员叫他陆远，说他是她弟弟。”

陆远听见自己的名字从门外传进来，攥紧了手里的刀。他没有追出去。

## B · 求助

陆敏没有出声。她看向小乔的口袋，再看了看小乔的眼睛。

小乔明白了。她自己拿出手机，手抖得按错一次，第二次拨通求助电话。

“喂，我在……”她报出店名和地址，“这里有人拿刀。”

陆远转过头：“放下！”

小乔把手机贴在胸前，没有交出去。“我已经说了。”电话仍接通着。

陆远看向收银抽屉，手没碰到它。他又看向门，退了一步。

“你明明认出我了。”他说。

陆敏说：“你先把刀放下。”

他没有放。他朝门走，小乔避到一旁，没有拦他。他停在门边，像是还想说什么，最后只说：“我知道你今晚在。”

门铃一响，他带着刀出去了。小乔和陆敏都没有追。钱还在抽屉里。

小乔握着电话，站在门外灯下：“他走了，没拿钱。店员好像认识他。”

陆敏走到她身边。她的手机震动：

> 陆远说你明早替他还我五千。你知道吗？

她看着消息，没有回复。她并不知道这笔钱是怎么来的，只知道自己没有答应替他还。

## C · 现金

“就这些。”

陆远把钱抓过去，塞进收银台上一个透明小袋。他一只手握刀，一只手攥着袋子，捏了捏里面薄薄的一叠。

“怎么就这么点？”

“店里就这些现金。”

小乔看了一眼空抽屉，对陆敏说：“给了就给了。你不用替店里拦他。”

陆远拿着钱往门口走。陆敏的手机在围裙里震动。她看见一条陌生号码发来的消息：

> 陆远说你明早替他还我五千。你知道吗？

“王昊？”她问，“我什么时候答应替你还钱？”

“你借他钱做什么？”

“说好买二手车跑单，后来让我押球花了。钱不够还。”他晃了晃手里的袋子，“这些也不够。”

小乔看看袋子，又看看他。她听见两人认识，却看不见陆敏的手机屏幕。

陆远对陆敏说：“他说明早还不上，就把聊天记录给一起干活的人看。你把租房的钱借我，剩下的我慢慢补。”

“妈说你最后一班。我以为你不想走之前闹大。”他把钱袋塞进怀里，又拿出来，最后还是攥在手上，“你就说不认识我。”

### C-R · 放回来

“刚才不是你给我的吗？”

“是。我不想你拿着刀在她面前晃。”

小乔靠着门，手还在抖。“钱给了就给了，我不替店里拦你。我想出去。”

陆远望着袋子，又望着她。她没有伸手来接。

他走回柜台，把袋子放下，自己退开一步。钱没有回到抽屉，但已经不在他手里。

“这点钱也补不上。”他盯着柜台，“我来之前真以为会多一点。”

小乔看他离门远了，自己走出去，拨通求助电话：“我在便利店门外。里面有人拿刀，钱刚才被他拿走，现在放回柜台了。”她没听见他的姓名，没有编一个。

陆远听着门外的声音，伸手去拿袋子，碰到袋口，又收回手。

## S · 他自己说

陆远问：“你明天几点走？”

“七点零五。”

他点了一下头，像是把这个时间记住了。他没有再拿刀，也没有追出去。

陆敏看了看门外的小乔，又看了看包里露出一角的车票，没有把票拿出来。

**完。**

---

## E · 他走了

**如果从 B 进入：** 他已经离开，没有拿钱，现金仍在抽屉里。小乔的求助电话早已接通。直接读下面的「门外的选择」。

**如果从 A-E 或 D-E 进入：** 陆敏说：“我不拦你。你要走，是你自己的事。”

陆远看着她，像在等她再说一句。他没有等到，握着刀往门口走。小乔让开路，站到更远的灯下；他没有追她。收银抽屉里的钱没有交给他。

**如果从 C-E 进入：** 陆远带着那袋刚从店里拿到的现金和刀离开。陆敏没有追。小乔自己走出门，拨通求助电话，说店里有人拿刀，带走了现金。

**如果从 D-G 进入：** 陆远刚才带着那袋现金和刀离开。小乔拨通求助电话，说他带走了现金。

**如果从 C-R-E 进入：** 陆敏朝门口走：“小乔，我过来了。”

陆远叫住她：“你连看都不看我？”

“我看见你了。我不跟你走。”

他望着放回柜台的袋子，空着那只手，握刀离开。小乔让开路，站到更远的灯下；他没有追她。钱曾被拿走，现在留在柜台上。

陆敏走到小乔身边。小乔仍在通话。门铃响过之后，两个人都没有朝陆远离开的方向去。

**如果从 D-G 进入：** 陆敏的手机此时震动，陌生号码发来消息：“陆远说你明早替他还我五千。你知道吗？”她没有答应过，也不知道这笔钱是怎么来的。

### 门外的选择

**如果第一次选了 A：** 小乔早已亲耳听见姓名和姐弟关系，也已告诉求助电话。她现在补充：“他走了。”陆敏说：“是。我也会说清楚。”继续读本节末尾。

**如果从 B、C 或 D 的路线进入：** 小乔知道两人认识，但不知道他的名字。陆敏可以：

- **E1 · 说出他的身份。** 陆敏说：“他是我弟弟，叫陆远。我会说清楚。”小乔对电话那头补充：“店员刚告诉我，他是她弟弟，叫陆远。”
- **E2 · 暂不主动说身份，让小乔说自己知道的。** 小乔问：“你认识他？”陆敏说：“认识。我现在说不出来。”小乔对电话那头说：“他走了。他们认识，我不知道他叫什么。”

小乔看着陆敏，问：“你现在要追吗？”

陆敏摇头。

“那你陪我站在有灯的地方。”小乔说，“我妈还不知道我在哪儿。”

小乔先给母亲发了位置，才把手机交回另一只手。陆敏站在她旁边。她们不必回去替任何人守门。

**完。**

---

## H · 她替自己答应

陆敏看着陆远：“我让你把钱拿走。我自己会说不认识你。”

**如果从 A-H 进入：** 陆远说：“她都听见你叫我了。”

陆敏看一眼门外的小乔：“我只替自己答应。我管不了她说什么。”小乔此前的求助和她亲耳听到的名字都还在。

**如果从 C-H 进入：** 陆远手里的透明袋还装着刚才拿到的钱。陆敏没有把袋子拿回来。

**如果从 C-R-H 进入：** 陆敏从柜台上拿起那袋他刚放回来的钱，递还给他。陆远接过袋子。

小乔在门外透过玻璃看见了。

**如果从 A-H 或 D-H 进入：** 陆敏打开抽屉，把现金放到柜台上。陆远拿过去，装进一个透明小袋。

陆远掂了掂袋子。“这不够。”

“我不会把我自己的钱再给你。”

“你刚才不是——”

“我能答应的就这些。”

陆远看了她很久，终于攥紧袋子，握着刀走向门。

**如果从 C-H 进入：** 小乔退到一旁，没拦他。等他带着钱出去，她自己出了门，拨通求助电话，说有持刀的人拿走了店里的钱。

**如果从 A-H、C-R-H 或 D-H 进入：** 小乔已在门外求助。她让开路，没有拦他。他带着钱出去，门铃在他身后响了一声。

陆敏望着门，像是在等他回头。他没有。

**如果从 A-H 进入：** 小乔对电话那头补充：“他走了，带着钱。刚才我听见她叫他陆远，说是她弟弟。”

**如果从 C-R-H 进入：** 小乔对电话那头说：“他把钱放回过柜台。后来店员又把那袋钱递给了他。”

**如果从 C-H 或 D-H 进入：** 小乔对电话那头说：“他带着钱走了。他们认识，我不知道他叫什么。”

陆敏拨通店长的电话。“店里出了事，有人拿刀把现金拿走了。”她停了一下，“我不认识他。”

打完电话，她发现小乔站在门外看她。她走出去，把交班单和笔一并带了出来。

“我答应他说不认识他。”陆敏说。

小乔说：“我会写我看见的。”

陆敏握着笔：“我没让你跟我说一样的话。”

“我知道。”小乔说，“我明天还要来上班，这张单我得留下。”

交班单上还留着她刚写的“少两块”。陆敏把笔放下。小乔拿回自己的手机，走到更亮的地方给母亲报平安，没有叫陆敏一起。

陆敏一个人站在店门边。包里露出那张明早的车票，她伸手把它推了回去。

**完。**

## Q · 走到门外

陆敏拿起自己的包，走出店门。小乔已经在外面，她的求助电话还通着。

**如果从 A-Q 进入：** 小乔早已亲耳听见姓名和姐弟关系，并已告诉电话那头。陆远还握着刀，店里的现金没有交给他。

**如果从 C-R-Q 进入：** 那袋曾被陆远拿走的钱留在柜台上；他还握着刀。小乔报告过钱被拿走又放回，但不知道他的名字。

**如果从 D-Q 进入：** 陆远还握着刀，店里的现金没有交给他。小乔知道两人认识，不知道他的名字。

**如果从 T-Q 进入：** 陆远自己放下了刀，也自己说出了名字。钱留在店里；若经过 C-R，钱曾被他拿走又放回柜台，否则一直在抽屉里。

**如果从 C-R-Q 或 D-Q 进入，陆敏可以：**

- **Q1 · 告诉小乔他的身份。** 陆敏说：“他是我弟弟，叫陆远。”小乔对电话那头说：“店员刚告诉我，他是她弟弟，叫陆远。”
- **Q2 · 先不主动说身份，让小乔按自己知道的事求助。** 小乔问：“你认识他？”陆敏扶着墙说：“认识。我现在说不出来。”小乔对电话那头说：“他们认识，我不知道他叫什么。”

**如果从 A-Q 或 T-Q 进入：** 小乔已经听见姓名，求助电话里也已说出；没有人要求她把听见的事收回。

**如果从 D-Q 直接离开、没有经过 D-K：** 陆敏的手机此时震动，陌生号码发来消息：“陆远说你明早替他还我五千。你知道吗？”她没有答应过，也不知道这笔钱是怎么来的。

“我们不用回去替他守着。”小乔说。她给母亲发消息，叫她别来店里，随后沿着亮着灯的街面往前走。

陆敏回头看了一眼。陆远还在店里。她不知道他接下来会不会走，也没有回去问。

她跟上小乔。

**完。**

## 附录 · 因果与完整路线

正文中的条件段都是须实际读出的场景，并非留给读者补写的对白。每次只选一项第一次选择，之后按节点继续；没有阅读倒计时。四种结局状态由人物行为产生，不以隐藏分数决定。

| 首次行动 | 即时行动与不可抹去的事实 | 后续不同在哪里 |
|---|---|---|
| A 叫名字 | 小乔亲耳听见姓名和姐弟关系；她拒绝闭嘴，自己出门并报告姓名。陆远退开，没有追她。 | 可立即跟小乔走；也可留下听到借款、下注和他选这班的原因。之后陆敏仍可帮助、如实对待或离开，但无法代小乔撤回姓名。 |
| B 示意求助 | 小乔拨通电话并说出持刀情况；陆远自己放弃拿钱，带刀离开。求助不能撤销。 | 只能处理他已经离开后的事实：安全后可说出身份或暂不主动说。迟来的消息透露他擅自声称陆敏会还钱，但没有现场自白；钱一直留在抽屉。没有人能在他离开后再把钱递给他。 |
| C 交出现金 | 陆远实际拿走现金；嫌少，听到债务消息后自己回身要求陆敏再借钱。 | 他可带钱走；陆敏可主动承诺掩饰；也可请他放回。C-R 中他自己放下袋子，小乔离店求助；若后来改变主意帮助，陆敏必须再次把袋子递给他。 |
| D 拒绝开抽屉 | 钱仍在抽屉；陆远移到门边，妨碍小乔出去。小乔自己要求离开。 | 后来交钱会真实改变钱的位置，陆远拿钱离开；继续拒绝时，小乔明确说会求助，他仍自己退开让她走。之后陆敏可离开、听他解释、协助或如实应对。 |

### 全部合法路线

- **A：** `A → A-Q → Q`；或 `A → A-L → A-E → E`、`A-H → H`、`A-T → T`、`A-Q → Q`。
- **B：** `B → E`。他已经离开，因此没有现场递钱或劝留的机会。
- **C：** `C → C-E → E`、`C-H → H`，或 `C → C-R → C-R-E → E`、`C-R-H → H`、`C-R-T → T`、`C-R-Q → Q`。
- **D：** `D → D-G → E`；或 `D → D-L → D-Q → Q`；或 `D → D-L → D-K → D-E → E`、`D-H → H`、`D-T → T`、`D-Q → Q`。
- **T：** `T → T-S → S`，或 `T → T-Q → Q`。陆远在这项选择之前已自己放下刀并说出名字；陆敏去留不撤销他的行动。
- **E 的门外选择：** A 的姓名已被小乔听见并报告；B、C、D 可选 `E1` 现在说明身份，或 `E2` 暂不主动说。**Q 的门外选择：** `C-R-Q`、`D-Q` 可选 `Q1` 说明身份或 `Q2` 暂不主动说；A 和 T 的姓名已说出，小乔按自己听到的报告。

**合流核对。** E 将 `C-E / D-G` 的持钱离开、`C-R-E` 的拿走后放回，以及其他路线钱未转手的情况分别写出；只有 B 和 D-G 在他离开后才收到借款消息。H 分写持钱、放回后再次交钱、新从抽屉交钱，以及小乔在店内或店外的情况。Q 分写持刀与放刀、钱在抽屉或柜台、姓名已知与否。T 只可从 A-T、C-R-T、D-T 进入，且每条路线中陆远事先都作出了可见让步；不是小乔替他作出决定。

### 可讨论的作者提案

- 赌债、借款对象和他害怕熟人知道的具体原因，是本稿的提案。他擅自声称姐姐会还钱，不代表她承担了债务。
- 结局停在事发当晚，不预判法律结果，也不保证陆敏赶上或错过次日的车。可讨论是否希望看到更远的生活后果。
- 单条路线的时长尚未排演或测量；6–10 分钟只是目标，不是已验证结果。
