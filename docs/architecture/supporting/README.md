# Supporting architecture files

Most readers do not need anything in this directory. Open the three HTML files
one level above instead.

- `specifications/` contains the editable, authored Archify JSON. These files
  define the diagram facts, stable IDs, labels, and geometry.
- `validation/` contains generated proof and review material: the Architecture
  Delta receipt, visual-check JSON, contact sheets, and screenshots.

Keep every visual-check contact sheet together with its same-prefix PNG files;
the contact sheet uses relative sibling links. Regeneration commands and the
current validation caveats are documented in `../README.md`.
