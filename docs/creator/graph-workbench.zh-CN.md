# 图中心创作工作台

使用至少 1280px 宽的桌面浏览器；本页随当前源码中的图中心工作流维护。
打开、重新打开或复制项目后，进入「创作工作台」。新建项目先填写「项目简报与创作设置」，
保存后进入来源。完整的角色、图片、视频与播放步骤仍见[创作者手册](manual.zh-CN.md)。

## 建立与修改故事

先确认来源和大纲，在「来源与大纲」准备故事分支建议。建议返回后成为可审阅的图草稿；
你可以修改正文和连接，再分别确认内容和应用故事路线。准备任务、发送、检查结果、
确认候选和应用路线是独立操作。浏览报告或保存草稿不会自动执行后续步骤。

创作工作台与专业工作台是同一剧情图的两种视图，不是两个故事或副本：创作视图自动排列
剧情并衔接制作；专业视图提供可缩放、平移的画布与结构规则。两者共用一份图草稿和
当前节点选择，切换仍走现有草稿保护。推荐流程中两者都属于「4/6 剧情图编辑」，
视图名称另行显示；序号是当前工作步骤，不是完成比例。来源页的分支建议仍属第 3 步。

点击真实节点，右侧「故事」显示正文、输入、
后续及该节点的全部剧本场次。同一地点重复出现的场次分别显示；场次序号属于剧本，
不会因点击图节点而改写。没有来源的已有规范图提供只读查看，并解释编辑前提。

每行的「+」只在该行添加节点。共同父节点和共同后续只有在该行所有成员满足条件时
才默认选择；否则由你明确指定，也可以留待连接。选择点的选项写在线上。
插行须选择精确连接，原选项文字和效果保留在输入边；原目标及其后续保留。
点击连接按钮或拖到目标节点均会先打开可审阅的修改预览，确认后才提交。

删除节点须选择删除方式。「仅删除，保留待连接」保留关联边的身份、文字和效果，
不级联删除其他剧情。安全绕过只适用于明确且无效果的唯一后续。当前开场不能删除。
结构撤销恢复这一步图草稿的内容与连接；它不回滚简报、已确认剧本或媒体批准。
修改后继续输入正文时，先处理当前内容，再决定是否撤销结构操作。

保存图草稿可以保留空正文、待连接及未完成汇合。确认内容要求正文完整、连接合法，
实际完整路线的选择数、结局数和汇合符合当前简报。目标不符时可查看目标调整预览，
明确提交后才修改简报；系统不会自动抬高容量。简报变化使旧确认需要重新审阅，
旧场次、镜头和媒体仍保留。过期草稿提供明确恢复操作，失败时保留原文。

## 阅读与制作

选择点和汇合默认只控制路线，不生成独立画面。需要该节点自己的剧本和镜头时，
明确启用「包含画面」，确认新的故事内容，再重新审阅下游；正文编辑不会代替这次决定。
阅读路线经过所有故事节点，只播放明确包含画面的节点所绑定的剧本。

右侧「制作」按剧本正式出现坐标列出全部场次与有序镜头，显示精确身份和时长。
「进入镜头制作」进入已有镜头工作区；在那里分别批准分镜、审阅关键帧候选、制作视频、
明确选择待审片段并播放。镜头批准缺失与故事绑定过期是不同状态。
图或剧本变化时暂停旧制作入口，保留旧镜头与媒体，重新核对当前绑定。

投产提案仍在「来源与大纲」整包审阅。已有制作内容的项目也可以确认并应用故事修改。
修改影响制作来源后，旧内容需要重建，故事播放暂停；原镜头与媒体仍保留。
完成当前来源、剧本和分镜评审后，点击「准备重建提案」，重新审阅戏剧意图与呈现方式，
再明确确认提案。确认后需要重新批准当前分镜，并检查、明确选用当前视频片段，才能恢复播放。
新的待审提案不会自动替换已建立内容的镜头入口。若审阅期间另一处修改了制作内容，
提案会提示过期；重新准备后按最新内容审阅。出现未知结果时，先处理旁边的原因。
保存、换页和重新打开均不会自动生成、批准或选择媒体。

## 桌面操作与恢复

长图随页面纵向滚动；并行节点保持同层，超出宽度时在图内横向平移。
右侧详情尽量对齐当前节点，靠近屏幕边界时保持在可见范围，内部内容可滚动。
详情默认宽 380px，紧凑桌面为 300px。拖动分隔线、方向键或 Home/End 调整宽度，
Shift 加快键盘调整，双击恢复自动宽度。拖动时 Escape 或 Tab 取消本次调整。
缩小浏览器临时钳制宽度，恢复尺寸后保留你的偏好。

选择节点、平移和详情宽度属于本浏览器的查看偏好。切换节点不产生新内容版本。
保存并关闭会先保存未完成的作者草稿，重新打开后恢复；明确强制关闭只丢弃尚未发送的编辑，
后台任务仍归原项目所有。候选取消、项目关闭和删除是不同操作。

本次工程验证和截图范围见[交付验收合同](../creative-workflow/graph-workbench-acceptance.md)。
工程检查通过后仍需作者实际试用；图片、声音与最终影片质量另行审阅。
