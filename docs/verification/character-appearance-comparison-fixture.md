# Character appearance comparison technical fixture

The browser regression in `frontend/e2e/cast-reference-studies.spec.ts` uses an
isolated fake runtime and mocked ImageGen delivery evidence to place five
recognizable repository-owned screenshots through the normal Characters UI.
It proves local gallery layout and state behavior only. It neither contacts an
image provider nor establishes a persistent production delivery or replacement
for separately retained live ImageGen proof.

The named candidates are Beacon console, Review shortcut, Workbench map,
Profile contact sheet, and Workspace correction. The fixture proves that the
gallery retains all five while a creator can explicitly compose, remove, and
replace a two-, three-, or four-image comparison set without implicitly
selecting an identity reference. Its desktop captures are 1440 and 1920 only.

Current product limitation: a truthful managed-image import remains
project-scoped. Because the gallery enumerates proposal deliveries only, it
cannot safely show imported unselected assets as character appearance options.
A character-owned imported-appearance membership is an unapproved future seam.
